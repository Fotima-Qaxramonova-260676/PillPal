# PillPal — GitHub Pages source (v6)

This version updates the homepage hero to use the same PillPal medicine bottle artwork shown in the PillPal promotional poster. The bottle image is included as `pillpal-poster-bottle.png`.

## Upload
1. Upload all four files in this folder to the root of your GitHub repository.
2. Replace the existing `index.html`, `styles.css`, and `script.js`; add/replace `pillpal-poster-bottle.png`.
3. Commit changes and wait for GitHub Pages to publish.
4. If a phone still shows an older version, refresh the page or open it in a private/incognito tab.

This remains a front-end demo; payment and cross-device data sync are not configured.

## Bottle illustration update
The hero uses `pillpal-bottle.svg`, an original vector illustration drawn for this site. It is not cropped from the poster. Keep the SVG in the repository root next to `index.html`.
