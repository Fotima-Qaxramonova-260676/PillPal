# PillPal — GitHub Pages source

This folder contains the static website files:
- `index.html` — page structure
- `styles.css` — visual design and responsive styles
- `script.js` — demo interactions

## Publish on GitHub Pages
1. Download and extract this ZIP.
2. Open your repository: https://github.com/Fotima-Qaxramonova-260676/PillPal
3. Upload these four files to the repository root, replacing the existing files when prompted.
4. Commit the changes to the `main` branch.
5. In Settings → Pages, make sure publishing is set to `main` and `/(root)`.
6. Wait a few minutes, then open https://fotima-qaxramonova-260676.github.io/PillPal/

This is a front-end demo. Data is stored in the current browser using localStorage; payment and real family sharing are not connected to a backend.
