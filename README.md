# PillPal — GitHub Pages source (v8)

The PillPal medicine bottle is embedded directly as inline SVG inside `index.html`. No separate bottle image or SVG file is required, so the illustration will still appear when the site is deployed.

## Upload
1. Upload `index.html`, `styles.css`, `script.js`, and `README.md` to the root of your GitHub repository.
2. Replace the existing files with these versions.
3. Commit changes and wait for GitHub Pages to publish.
4. If a phone still shows an older version, refresh the page or open it in a private/incognito tab.

This is a front-end demo. Payment and cross-device data sync are not configured.


Version 9 update: the inline SVG medicine bottle uses the site accent variables (`--accent` and `--accent2`), so changing the theme or custom accent also recolors the bottle cap, label mark, and colored capsule details. No separate bottle image is required.
